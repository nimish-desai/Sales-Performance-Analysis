# &#x20;**Sales Performance Analysis using Microsoft Excel**



#### ***Project Overview***

This project analyses a simulated retail sales dataset using Microsoft Excel. The objective is to evaluate sales performance across different cities, products, and sales channels, and present the findings through an interactive-style dashboard.



* ###### Tools Used
1. &#x20;Microsoft Excel
2. &#x20;Excel Formulas
3. &#x20;PivotTables
4. &#x20;PivotCharts
5. &#x20;Data Analysis and Visualization



* ###### &#x20;Dataset

The dataset contains 30 fictional retail orders covering January and February 2026.



Key fields include:

* Order ID
* Order Date
* City and Region
* Product and Category
* Units Sold
* Unit Price
* Discount
* Sales Channel
* Payment Mode



A calculated Net Sales field was created using the formula:



`Net Sales = Units Sold × Unit Price − Discount`



###### Key Performance Indicators(KPI)

* Total Net Sales: ₹655,400
* Total Orders: 30
* Total Units Sold: 75
* Average Net Sales per Order: ₹21,846.67



###### Key Findings

* Bengaluru recorded the highest city-level net sales at ₹182,700.
* Laptops generated the highest product-level net sales at ₹483,500.
* Laptops contributed approximately 73.8% of total net sales.
* Navi Mumbai recorded the lowest city-level net sales at ₹72,650.



###### Analysis Performed

* Calculated sales KPIs using Excel formulas.
* Analysed sales performance by city using PivotTables.
* Compared product-level revenue.
* Created charts to visualise city and product sales performance.
* Prepared a dashboard to present the key findings.



###### Project Files

* `sales\_analysis.xlsx` – Excel workbook containing the dataset, calculations, PivotTables, charts, and dashboard.
* `Data/Sales\_Data.csv` – Original simulated sales dataset.
